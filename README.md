### 🚀 Now building

**[consolidated_agent_release_deployment](https://github.com/jahanvi15/consolidated_agent_release_deployment)**: one release pipeline for AI agents.
Every agent change goes through the same checks before it ships, on GitHub Actions today and Azure DevOps next.

```text
agent change ──▶ checks ──▶ ci-pass ✅ ──▶ release
```

- 🧪 Deterministic sample agents as test fixtures: no network, no LLM, fast and repeatable
- 🔒 Protected `main`: every change goes through a PR and a single `ci-pass` gate
- 📦 Zero runtime dependencies, platform-neutral core behind a CLI

### 🌱 Learning in public

Every push to my project comes with a beginner-friendly journal entry and glossary update in [`learning/`](https://github.com/jahanvi15/consolidated_agent_release_deployment/tree/main/learning). If you're new to CI/CD, start there.
